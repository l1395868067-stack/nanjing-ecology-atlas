ABOUT THIS ATLAS

如何读这张地图

范围是南京全市行政辖区及长江南京段。当前收录36处代表性地点，包含自然保护地、河湖、山林、生态修复案例与科普场所；这几类性质不同，不能混作同一份法定名录。

直接打开也能用

本文件自带全部资料、位置示意与交互代码。双击打开即可搜索、分类筛选、缩放、查看来源，并导出筛选数据。离线河流线仅表现大致走向，不是河岸、航道、行政界或保护区界。

在线街道底图

在线底图使用 OpenStreetMap，需要网络。通过附件中的 start_local.py 或 Windows 的 start_windows.bat 启动后，可点“在线底图”。直接使用 file:// 打开时不会向瓦片服务器发出无来源请求。没有 Python 也可正常使用离线网页，或点击地点详情中的“在地图网站核对位置”。

数据如何理解

地点文字以列出的公开来源为依据。“观察主题”是编者的教学建议。坐标含公开地图POI近似换算、文献范围内锚点及人工初定位，均不是测绘成果、精准入口或边界。未知处已标明，不据此导航、进入保护区或判断行政归属。

诗词与地点

已放入《钟山即事》《泊秦淮》两条区域关联样例，并写明关联层级。未将此前285条诗句自动绑定地点；题名或意象相似不足以证明创作位置。

维护与公开展示

资料整理日期：2026-11-02。开放、预约与现场管控请另向管理方确认。对外发布前应进一步核验待核坐标，使用合规底图，并由项目负责人确认资料和版权要求。GeoJSON 只有地点数据，不包含保护区或行政区域面数据。

OpenStreetMap 在线瓦片使用说明 ↗

在线底图需要本地网页服务

你现在是双击文件打开的。离线示意、搜索、筛选和地点详情已经可以使用。

切换街道底图：解压完整文件包，在装有 Python 3 的电脑上双击 start_windows.bat，或运行 python start_local.py。启动器只服务当前电脑的 localhost，不上传地点资料。

不运行启动器，也可在地点详情点击“在地图网站核对位置”，打开对应位置的在线地图。
