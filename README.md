# 南京生态图鉴（GitHub Pages 部署包）

这是南京生态图鉴的静态网站发布包。网站入口是 `index.html`，可直接部署到 GitHub Pages、Netlify 或其他静态托管服务。

## 内容

- `index.html`：自包含交互地图，包含搜索、分类筛选、行政区筛选、沿江筛选、诗词筛选、地点详情、导出功能和手机布局。
- `nanjing_ecology_map.html`：与入口相同的原始文件名副本，便于继续编辑或本地打开。
- `nanjing_ecology_sites.xlsx`：地点数据表。

## 发布说明

网页不依赖本地脚本、图片或 CSS 文件，直接把 `index.html` 放在网站根目录即可。网页的“离线示意”模式无需联网；切换到“在线底图”时会使用 OpenStreetMap 瓦片，因此访问者需要联网，并应遵守 OpenStreetMap 的瓦片使用政策。

## 数据边界

当前版本是 36 处代表性地点的首批资料和交互原型，不是完整生态地点名录，也不包含行政界线、保护区法定边界或生态红线。部分坐标为概略锚点，不能作为精准导航、开放承诺或进入保护区的依据。
